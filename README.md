# Kasm Workspaces Registry

This repository contains custom [Kasm Workspaces](https://kasm.com/) images tailored for convenience, productivity, and specialized workflows.

## Available Images

### **Fedora Core Workspace**

A Fedora-based workspace that includes:

* **Bambu Studio** – for managing and slicing 3D printer projects.
* **Firefox** – a stable and privacy-focused web browser.

This image is designed to provide a ready-to-use environment for 3D printing workflows directly in your Kasm deployment.
